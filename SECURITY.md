# Security Policy

## Supported Versions

Sentinel HealthOS is currently in active development.

Security updates will be provided for the latest version of the platform.

| Version | Supported |
|---------|-----------|
| Main | ✅ Yes |
| Older versions | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public issue.

Instead, report it privately by emailing:

📧 sixpoint0industries@gmail.com

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

We aim to:

- Acknowledge reports within 48 hours.
- Investigate all valid reports promptly.
- Release security fixes as quickly as possible.

## Responsible Disclosure

We appreciate responsible disclosure and will recognize contributors who help improve the security of Sentinel HealthOS.

Thank you for helping us build trustworthy AI for public health.
