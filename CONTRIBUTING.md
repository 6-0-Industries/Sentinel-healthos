# Contributing to Sentinel HealthOS

Thank you for your interest in contributing to Sentinel HealthOS.

We welcome contributions from:

- Public Health Researchers
- AI Engineers
- GIS Specialists
- Data Scientists
- Software Developers
- UX/UI Designers
- Healthcare Professionals
- Students

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test your work.
5. Submit a Pull Request.

## Coding Principles

- Ethical AI
- Transparent algorithms
- Evidence-based development
- Secure by design
- Public health first

Together we can build trusted AI for humanity.
